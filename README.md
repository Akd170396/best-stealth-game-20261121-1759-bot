[best-stealth-game-20261121-1759](https://make.fun/bounty/best-stealth-game-20261121-1759):
The Quiet Vault, a top-down stealth heist. Slip past lantern guards whose vision
cones stop at walls and crates, take the gem, and reach the exit unseen — three
floors, learnable patrols, a detection meter that gives you a chance to recover,
and footsteps you can hear coming.

Run it: `node serve.ts`, then open http://localhost:8080 — WASD/arrows to move,
Shift to sneak. The hand-in program is `main.ts` (`mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`).
